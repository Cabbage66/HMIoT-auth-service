# 项目需求（整理版）

多网融合人机物电子认证服务软件项目需求如下。

## 一、安卓客户端

### 1. 注册与登录

* 支持用户注册与登录。注册时提交用户名、密码、姓名、手机号、邮箱、证件号等基础信息。
* 支持查看用户注册记录、审核进度和审核结果。
* 支持保存和使用管理端签发的数字证书，数字证书可用于辅助验证或直接登录。
* 支持使用指纹、人脸、声纹等生物特征辅助验证或登录。

### 2. 生物特征采集与认证

* 支持采集指纹、人脸、声纹等生物特征信息，并上传服务端或模型侧进行管理。
* 生物特征数据需支持全生命周期管理，包括采集、上传/传输、模板建立、模板存储、模板撤销、审核、重新采集及留痕。
* 生物特征模板和保护密钥需受密码机制保护。
* 指纹、人脸、声纹应区分比对模式：指纹可优先使用终端本地采集和本地比对；声纹、人脸可支持本地采集、服务端或模型侧远端比对。
* 声纹能力需对接 `voiceprint-engine`。

### 3. 终端信任监控

* 支持采集并上报终端设备基础信息、系统运行状态、软件状态、硬件状态、业务运行日志、用户操作日志、外设连接、关键数据读写等信息。
* 终端数据采集需支持定时采集和异步事件采集，并在上报前完成清理、转换、分类和标准化处理。
* 支持接收并展示服务端返回的信任评估结果、认证状态、设备状态、策略执行情况、安全等级和风险告警。
* 检测到异常进程、异常行为或安全风险时，支持告警上报和必要的访问阻断。

### 4. 功能访问与策略执行

* 支持展示系统内置功能、应用等资源。资源可由业务应用系统提供，当前可暂用数据库模拟。
* 用户访问功能或应用前，客户端需根据服务端/管理端配置的认证协议，引导用户完成对应认证流程。
* 身份认证通过后，客户端需配合服务端完成信任评估，并根据评估结果判断是否允许访问。
* 支持接收服务端下发的认证策略、采集监控策略、安全基线策略，并保存到本地策略库后执行。
* 当终端环境异常、用户行为异常、绑定关系不满足或信任等级不足时，支持按照服务端策略执行二次认证。

## 二、网页客户端

* 支持用户通过 USB 认证模块登录。用户插入 USB 认证模块后输入 PIN 完成登录。
* 支持访问业务应用系统提供的功能、应用等资源。
* 访问业务应用时，应支持携带身份票据或调用单点登录流程完成身份确认。

## 三、管理端

### 1. 管理员登录与权限控制

* 支持管理员登录。
* 涉及策略配置、模型配置、证书操作、导入导出等敏感操作时，后续应支持管理员 PIN 或等价二次鉴权。

### 2. 用户管理

* 支持审核用户注册申请，并记录审核成功、驳回及驳回原因等详细信息。
* 支持查看、更新用户基础信息。
* 支持从后量子属性密码标识应用服务系统获取并更新用户属性信息。
* 支持离线注册用户，包括手动新增用户基础信息、批量导入用户基础信息和生物特征信息。
* 离线注册时支持导入证书文件，解析证书 DN 或用户标识，并与用户身份记录绑定。

### 3. 生物特征与证书管理

* 支持管理用户指纹、人脸、声纹等生物特征信息。
* 支持审核用户提交的生物特征信息。
* 支持生物特征模板撤销、重新采集和审批留痕。
* 支持接入数字证书模块，完成用户证书签发、绑定、吊销和审计。

### 4. 设备与绑定管理

* 支持对业务终端、物联网设备、摄像头、感知节点等设备/物体实体进行管理。
* 管理员可新增、编辑、删除、启停设备/物体身份信息。
* 支持维护用户与终端、动态生物特征、物联网设备、应用资源之间的绑定关系。
* 设备/物体实体不作为人员用户的直接认证因子，但应作为独立实体认证对象和访问控制约束参与认证决策。
* 用户身份认证通过后，系统还需校验关联设备/物体的合法性、有效性、绑定关系和当前状态。
* 支持记录绑定、解绑、变更、失败原因和操作者。

### 5. 认证协议编配与策略管理

* 支持按不同业务场景匹配不同认证模式，并下发给客户端或认证服务执行。
* 支持的场景包括用户登录、功能/应用访问、二次认证等。
* 支持为系统内功能、应用配置安全等级、认证方式、终端信任评估等级要求和信任阈值。
* 支持可视化编排认证方式，将多个认证能力按业务场景编排为规则，并由执行引擎按顺序调度。
* 支持配置认证方式、组合方式、调用顺序、认证比对模式、适用场景、安全等级、信任等级阈值、会话有效期等参数。
* 多因子认证作为认证协议编配的一类组合结果纳入统一编排。
* 策略管理包括全局策略、用户策略、设备策略、服务/应用策略、安全基线策略，支持默认拒绝、手动配置、自动发现或等价策略模式。

### 6. 日志审计

* 支持查看用户登录日志，包括登录设备、认证方式、IP、时间、认证结果和详细信息。
* 支持证书审计日志，包括证书签发、绑定、吊销等操作记录。
* 支持生物特征提交审批记录和生物认证流水。
* 支持查看信任评估日志，记录评估请求、评估结果、信任等级、异常原因等信息。
* 支持查看终端设备环境记录，记录终端安全性信息、环境上报数据和风险告警。
* 日志审计需覆盖身份注册、在线注册签名校验、离线导入、绑定变更、认证流水、票据签发与验证、SSO 访问、跨域互认、策略下发与执行结果。

## 四、服务端

### 1. 身份信息注册与管理

* 支持身份信息注册，包括在线注册、离线注册和批量导入。
* 身份信息范围不只限于人员用户，还应覆盖用户、设备、物体等实体身份信息。
* 支持维护人员用户、业务终端、物联网设备、摄像头、感知节点等实体身份信息。
* 支持用户、设备、物体、终端、应用之间的关联映射和绑定关系管理。
* 在线注册流程需支持外部系统上报机制：动态生物特征系统、广域低功耗系统、后量子属性系统向本系统发起注册或属性更新时，本系统返回随机码；外部系统携带随机码、注册/属性信息及签名提交；本系统校验签名与随机码后完成注册、更新或关联映射。
* 离线注册流程需支持管理员新增用户、导入用户数据、导入生物特征数据、导入证书并完成证书绑定。

### 2. 身份认证服务

* 支持用户、设备等实体对象的身份认证。
* 支持管理端配置的动态身份认证流程。
* 支持用户名/口令、数字证书、USB 认证模块+PIN、指纹、人脸、声纹、动态生物特征等认证方式。
* 支持与加密卡或 USB 认证模块的密码服务接口，完成必要的密码运算和身份认证。
* 认证请求中应包含认证主体类型，服务端根据主体类型选择对应认证处理模块和认证协议流程。
* 支持自适应认证协议动态生成：根据用户类型、终端类型、应用场景、应用安全等级、管理端策略，返回本次认证应执行的认证模式和协议参数。
* 支持接收、存储并执行管理端下发的认证协议编排配置。
* 用户访问更高安全等级应用、终端环境异常、用户行为异常、绑定关系不满足或信任等级不足时，应触发重新认证、关键因子认证或增强因子认证。
* 二次认证失败时，应阻断登录或业务访问。

### 3. 身份票据与单点登录

* 认证成功后，服务端需使用系统私钥生成身份票据。
* 身份票据至少包含用户身份标识、信任评估结果/等级、有效期、签名信息。
* 支持认证会话保持、票据刷新、保活和失效处理。
* 支持下发用户身份票据，并验证本系统或其他系统提交的身份票据。
* 客户端认证成功后获取身份票据；安卓应用、网页端或浏览器访问业务系统时携带票据；业务系统调用本系统票据验证接口确认用户是否合法。
* 票据验证内容包括票据真实性、有效性、签名有效性、信任评估结果一致性，以及申请应用所需信任等级是否不高于票据中的当前信任等级。
* 若票据信任等级不足，服务端应向业务系统返回重新认证或增强认证返回码，业务系统据此引导用户重新认证。
* 业务应用系统通过单点登录接口确认用户身份是否合法，并完成应用登录。
* 跨人机物系统访问需支持免重复登录。系统 A 认证成功后，用户访问系统 B 的应用 B 时，应能通过身份票据或互认接口完成访问。

### 4. 设备/物体认证与绑定校验

* 支持对业务终端、物联网设备、摄像头、感知节点等设备/物体实体进行合法性、有效性和状态校验。
* 支持校验用户与终端、动态生物特征、物联网设备、应用资源之间的绑定关系。
* 设备/物体实体作为独立实体认证对象和访问控制约束参与认证决策。
* 用户身份认证通过后，仍需校验关联设备/物体的合法性、有效性、绑定关系和当前状态。
* 绑定关系、设备状态或物体状态不满足策略要求时，应拒绝登录或拒绝访问，并记录可审计原因。

### 5. 信任评估模型与访问决策

* 支持上传信任评估模型所需信息，并接收、记录信任评估模型返回结果。
* 信任评估服务需对接 `UEBA4.2`，并定义输入、输出和落库字段。
* 信任评估输入至少包括主体信息、访问请求、资产状态、资源访问要求、风险威胁、用户历史行为、设备状态、终端环境、认证记录、业务访问日志等。
* 信任评估输出应包括信任分值、信任等级、异常指标、重要告警、异常日志或拒绝原因。
* 信任评估应包括实体信任评估、访问行为信任评估、静态场景/基线评估。
* 评估结果需进入认证与访问决策。认证通过后，系统仍需根据用户、设备、物、应用资源安全等级和信任阈值判断是否允许访问。
* 信任评估需支持持续评估和周期性更新；历史信任值、时间衰减、滑动窗口或等价机制的实现边界需在模型侧或服务侧明确。
* 当信任评估发现身份异常、终端异常、行为异常或风险等级升高时，服务端应触发策略调整、二次认证或访问阻断。

### 6. 策略下发与终端环境数据处理

* 支持接收终端上报的设备环境、终端状态、用户行为、业务日志和风险告警等数据。
* 支持对终端上报数据进行格式化、标准化、清洗、分类和落库。
* 支持向客户端下发认证策略、采集监控策略、安全基线策略和二次认证策略。
* 支持记录策略下发、策略执行结果和策略变更历史。

### 7. 日志与审计服务

* 支持记录并查询身份注册、在线注册签名校验、离线导入、证书操作、生物特征操作、绑定变更、认证流水、票据签发与验证、SSO 访问、跨域互认、信任评估、终端环境上报、策略下发与执行结果等日志。
* 信任评估信息日志和终端设备环境记录可使用数据库或文件方式记录。
* 认证失败、票据校验失败、绑定校验失败、信任评估拒绝、跨域互认失败等场景需记录失败原因。

### 8. 对外接口与模型集成

* 与后量子属性密码标识应用服务系统对接，请求、接收并更新用户属性信息。
* 与动态生物特征系统对接，支持认证用户步态等动态生物特征，并支持人员用户实体身份认证信息上报。
* 与广域低功耗通信安全融合应用技术原型系统对接，支持物联网设备接入、物联网实体身份认证信息上报和物联网实体信任评估结果获取。
* 与异构认证体系智能互认系统对接，支持跨域标识验证、身份认证结果互认，必要时协同原域系统完成认证。
* 与业务应用系统对接，提供单点登录与票据验证接口，供业务应用确认用户身份是否合法。
* 与密码卡、加密卡或 USB 认证模块对接，调用密码服务接口完成密码运算和 USB 认证模块身份认证。
* 与 `voiceprint-engine` 对接，支持声纹注册、特征提取、比对认证、阈值配置、失败原因返回和模型服务健康检查。
* 与 `UEBA4.2` 对接，支持评估请求、评估结果、异常指标、日志路径/数据库字段和模型不可用时的降级策略。

## 五、核心业务流程（参考）

### 1. 用户注册与审核流程

* 用户在客户端提交注册信息和必要认证材料。
* 管理端审核注册申请，记录审核结果和原因。
* 审核通过后，用户身份信息、生物特征、证书和绑定关系进入系统统一管理。

### 2. 离线注册流程

* 管理员在管理端新增用户或批量导入用户信息。
* 管理员可导入生物特征信息和证书文件。
* 系统解析证书 DN 或用户标识，与用户身份记录建立绑定关系。

### 3. 用户登录与访问流程

* 用户通过安卓客户端或网页客户端发起登录。
* 系统根据认证主体、终端、应用场景和管理端策略返回认证协议。
* 用户完成对应认证方式后，服务端进行身份认证、绑定校验和信任评估。
* 认证和评估通过后，服务端签发身份票据。
* 用户访问业务应用时携带票据，业务应用通过本系统验证票据后决定是否允许访问。

### 4. 终端绑定访问流程

* 管理员将用户与指定终端绑定。
* 用户登录时，系统校验 USB 认证模块/PIN、用户身份和终端绑定关系。
* 用户在绑定终端上可继续认证和访问；在未绑定终端上应被拒绝登录或拒绝访问。

### 5. 动态生物绑定访问流程

* 管理员将用户与动态生物特征系统中的步态等动态生物特征绑定。
* 用户登录或访问时，系统校验持有因子和动态生物特征匹配结果。
* 动态生物特征不匹配时，应拒绝登录或拒绝访问。

### 6. 物联网设备绑定访问流程

* 管理员将用户、终端和广域低功耗物联网设备建立绑定关系。
* 用户登录或访问时，系统校验物联网设备接入状态、合法性和绑定关系。
* 设备未接入、状态异常或绑定不一致时，应拒绝登录或拒绝访问。

### 7. 跨系统与跨域访问流程

* 用户在人机物系统 A 完成认证并获得身份票据。
* 用户访问人机物系统 B 或其他业务系统时，通过身份票据、互认接口或异构认证体系智能互认系统完成身份确认。
* 互认成功时允许访问；互认失败、票据无效或信任等级不足时触发重新认证、增强认证或拒绝访问。

  * Axios

  * Spring Security、JWT
