# 阶段7：信任评估与风险可视化（实施计划与实现结果）

## 一、实施计划

### 1. 目标

实现管理端“信任评估与风险可视化中心”，覆盖 UEBA 健康检查、信任评估记录、终端事件、IoT 设备状态监控与可视化图表，支撑风险态势观测与联调定位。

### 2. 实施范围

- 页面：新增 `/admin/trust-risk`。
- 信任评估：
  - 查询评估记录、查看详情。
  - 接口：`/api/v1/trust-assessments`、`/api/v1/trust-assessments/{id}`。
- UEBA 健康：
  - 接口：`/api/v1/trust-assessments/ueba/health`。
- 终端事件：
  - 查询事件列表。
  - 接口：`/api/v1/terminal-events`。
- IoT 状态：
  - 查询状态列表、按设备主动刷新状态。
  - 接口：`/api/v1/iot-device-statuses`、`/api/v1/devices/{deviceEntityId}/iot-status/query`。
- 可视化：
  - 使用 ECharts 展示风险等级分布和 IoT 可信状态分布。

### 3. 验收标准

- 阶段7页面可完整加载四类数据并支持筛选/分页/详情操作。
- 图表可随数据刷新更新。
- 构建通过，菜单路由可达。
