# 前端项目开发规划（管理端 + 网页客户端）

## 目标

在 `frontend` 内实现可上线的前端工程，覆盖管理端与网页客户端，满足《项目需求-整理版》和《测试方案_回忆版》对应前端能力，并与 `backend` 阶段0-10接口联调。

## 分阶段安排

- 阶段0：工程初始化与基础规范
- 阶段1：登录与会话基础
- 阶段2：用户管理与属性更新
- 阶段3：证书与生物特征管理
- 阶段4：终端/物联网与绑定管理
- 阶段5：策略编排与应用资源管理
- 阶段6：网页客户端应用访问与SSO
- 阶段7：信任评估与风险可视化
- 阶段8：审计中心与检索导出
- 阶段9：联调、稳定性与验收

## 上线基线

- 构建产物可生成并可由 Nginx 托管。
- API 请求规范统一（鉴权、错误码、超时、重试策略）。
- 管理端与网页端关键流程可按测试方案完整演示。
- 前端日志与错误处理可定位问题并支撑联调。
