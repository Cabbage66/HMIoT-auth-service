# 阶段8：审计中心与检索导出（实施计划与实现结果）

## 一、实施计划

### 1. 目标

实现管理端“审计中心与检索导出”页面，支持多源审计数据统一检索、时间范围筛选、结果分页展示和 CSV 导出，满足测试与上线可观测性要求。

### 2. 实施范围

- 新增页面与路由：`/admin/audit-center`。
- 审计数据源整合：
  - 用户维度操作（用户管理数据）
  - 证书操作（证书列表数据）
  - 生物认证流水（生物认证记录）
  - 信任评估记录（信任评估结果）
  - 终端事件日志（终端事件记录）
- 页面能力：
  - 关键字检索（操作者、对象ID、操作类型、详情）
  - 时间区间筛选
  - 日志源多选筛选
  - 审计详情查看
  - CSV 导出（UTF-8 BOM）

### 3. 验收标准

- 审计中心可稳定加载并展示多源数据；
- 检索、分页、详情、导出功能完整可用；
- 菜单与路由可达，构建通过。
