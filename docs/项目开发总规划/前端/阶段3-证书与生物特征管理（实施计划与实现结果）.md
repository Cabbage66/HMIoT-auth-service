# 阶段3：证书与生物特征管理（实施计划与实现结果）

## 一、实施计划

### 1. 目标

实现管理端证书与生物特征管理完整功能，覆盖证书签发/绑定/吊销、生物模板审核/撤销、生物认证流水查询，形成阶段3可验收版本。

### 2. 实施范围

- 页面：新增管理端“生物凭据管理”主页面 `/admin/credentials`。
- 模块A 证书管理：
  - 查询证书列表（按用户名/状态）。
  - 证书签发（`/certificates/issue`）。
  - 证书绑定（`/certificates/bind`）。
  - 证书吊销（`/certificates/{id}/revoke`）。
- 模块B 生物模板审核：
  - 查询模板（用户/类型/审核状态/模板状态）。
  - 模板审核通过/驳回（`/biometric-templates/{id}/review`）。
  - 模板撤销（`/biometric-templates/{id}/revoke`）。
- 模块C 生物认证流水：
  - 按用户/类型/结果查询认证流水（`/biometric-auth-records`）。
- 风格实现：
  - 严格复用现有阶段1/2后台视觉系统和 `frontend-style-pages` 风格约束。

### 3. 验收标准

- 三个子模块均可独立完成查询与操作，且接口返回结果可回显。
- 关键动作（签发/绑定/吊销/审核/撤销）均有前端交互与异常处理。
- 构建通过，路由与菜单可稳定访问。

  - `frontend/src/router/index.ts`
  - `frontend/src/views/admin/AdminDashboardView.vue`
  - `frontend/src/views/admin/AdminUsersView.vue`

### 2. 功能完成度

- 证书管理：
  - 支持证书列表查询（用户名/状态）。
  - 支持证书签发（用户ID或用户名 + 公钥PEM）。
  - 支持证书绑定（序列号、指纹、证书PEM等）。
  - 支持证书吊销（强制输入吊销原因）。
- 生物模板审核：
  - 支持模板列表查询（用户ID、类型、审核状态、模板状态）。
  - 支持审核通过。
  - 支持审核驳回（强制输入驳回原因）。
  - 支持模板撤销（强制输入撤销原因）。
- 生物认证流水：
  - 支持按用户ID、类型、认证结果查询。
  - 支持分页展示关键字段（分数、阈值、结果、失败原因、时间）。

### 3. 风格与交互

- 页面采用既定后台风格：渐变头部、侧栏导航、卡片容器、工具栏筛选、表格分页。
- 操作反馈完整：加载态、成功提示、失败提示、关键动作二次输入对话框。
- 与阶段1/2会话与路由守卫机制兼容，不影响已有模块。

### 4. 验证记录

- 构建验证：`npm run build` 成功。
- 运行验证：`npm run dev -- --host 0.0.0.0 --port 3002` 启动成功，访问 `http://localhost:3002/`。
- 备注：构建存在 Rolldown pure annotation 与 chunk size 警告，不影响阶段3功能验收。
