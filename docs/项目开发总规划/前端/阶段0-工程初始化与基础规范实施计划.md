# 阶段0：工程初始化与基础规范实施计划

## 阶段目标

完成前端工程基础设施，形成可持续迭代的管理端与网页客户端统一项目骨架。

## 实施内容

- 技术栈落地：Vue3 + TypeScript + Vite + Element Plus + Pinia + Vue Router + Axios + ECharts。
- 基础目录：`api`、`router`、`stores`、`views/admin`、`views/web`。
- 路由初始化：管理端与网页端基础路由和页面占位。
- 状态管理：管理员会话 token 基础存储与清理。
- HTTP封装：统一 `baseURL`、超时、Authorization 请求头注入。
- 运行配置：Vite 端口固定 `3002`，代理 `/api -> http://localhost:8080`。
- 文档输出：阶段规划文档与实现结果文档。

## 验收标准

- `npm run dev -- --host 0.0.0.0 --port 3002` 可启动。
- 首页路由可进入管理端登录页与网页端登录页。
- `npm run build` 通过，无 TypeScript 构建错误。
- 前端目录结构支持后续阶段直接扩展。
