# 阶段1：登录与会话基础（实施计划与实现结果）

## 一、实施计划

### 1. 目标

基于 `frontend/frontend-style-pages` 的风格规范，实现管理端与网页客户端的真实登录流程、会话管理与路由守卫，形成后续阶段可直接联调的安全入口层。

### 2. 实施范围

- 管理端：管理员账号密码登录，接入后端 `/api/v1/auth/admin/login`。
- 网页客户端：USB 两步登录流程，接入后端：
  - `/api/v1/auth/usb/challenge`
  - `/api/v1/auth/usb/verify`
- 会话体系：管理员与网页用户双会话持久化（token + profile）。
- 路由守卫：未登录禁止访问受保护页面，已登录自动跳转。
- 样式体系：统一采用 `frontend-style-pages` 的配色、布局、渐变头部、侧栏和卡片规则。
- 错误处理：统一 API 响应解析与异常提示，保留服务端 message。

### 3. 验收标准

- 管理端登录成功后进入 `/admin/dashboard`。
- 网页端完成 challenge + verify 后进入 `/web/apps`。
- 刷新页面后会话仍有效；退出后受保护路由不可访问。
- `npm run build` 成功。

## 二、实现结果

### 1. 代码落地

- API 与类型：
  - `frontend/src/api/http.ts`：统一响应结构校验、错误转换、按作用域注入 token。
  - `frontend/src/api/auth.ts`：封装管理员登录与 USB 登录接口。
  - `frontend/src/types/api.ts`、`frontend/src/types/auth.ts`：阶段1接口类型定义。
- 状态管理：
  - `frontend/src/stores/auth.ts`：管理员/网页用户双会话存储与清理。
- 路由与权限：
  - `frontend/src/router/index.ts`：新增 `authScope` 路由元信息与全局守卫。
- 页面实现（按风格页重构）：
  - `frontend/src/views/admin/AdminLoginView.vue`
  - `frontend/src/views/admin/AdminDashboardView.vue`
  - `frontend/src/views/web/WebLoginView.vue`
  - `frontend/src/views/web/WebAppsView.vue`
  - `frontend/src/style.css`

### 2. 功能说明

- 管理端登录：真实调用后端鉴权接口，成功后持久化管理员会话并跳转后台。
- 网页端 USB 登录：先获取挑战码，再提交签名验签，成功后写入用户会话并进入应用访问页。
- 路由安全：`/admin/dashboard` 需管理员会话；`/web/apps` 需用户会话。
- 会话隔离：管理员 token 与用户 token 分离存储，避免互相覆盖。

### 3. 验证结果

- 本地构建：`npm run build` 通过。
- 运行验证：`npm run dev -- --host 0.0.0.0 --port 3002` 可启动并访问。

## 三、结论

阶段1已完成，满足进入阶段2（用户管理与属性更新）的前置条件。
