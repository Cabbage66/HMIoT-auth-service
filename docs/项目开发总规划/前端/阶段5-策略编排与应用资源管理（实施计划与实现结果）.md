# 阶段5：策略编排与应用资源管理（实施计划与实现结果）

## 一、实施计划

### 1. 目标

实现管理端“应用资源管理 + 认证方式管理 + 认证策略管理 + 安全基线管理 + 发布记录查询”完整功能，形成策略编排与下发操作闭环。

### 2. 实施范围

- 页面：新增 `/admin/policy-app`。
- 应用资源管理：
  - 查询、创建、编辑、启用/禁用。
  - 接口：`/api/v1/apps`、`/api/v1/apps/{id}`、`/api/v1/apps/{id}/status`。
- 认证方式管理：
  - 查询、创建、编辑、启用/禁用。
  - 接口：`/api/v1/auth-methods`、`/api/v1/auth-methods/{id}`、`/api/v1/auth-methods/{id}/status`。
- 认证策略管理：
  - 查询、创建、编辑、启用/禁用、发布。
  - 接口：`/api/v1/auth-policies`、`/api/v1/auth-policies/{id}`、`/api/v1/auth-policies/{id}/status`、`/api/v1/auth-policies/{id}/publish`。
- 安全基线管理：
  - 查询、创建、编辑、启用/禁用、发布。
  - 接口：`/api/v1/security-baselines`、`/api/v1/security-baselines/{id}`、`/api/v1/security-baselines/{id}/status`、`/api/v1/security-baselines/{id}/publish`。
- 发布记录：
  - 查询策略发布记录。
  - 接口：`/api/v1/policies/publish-records`。

### 3. 验收标准

- 五个子模块均具备可执行前端操作链路并联调后端成功回显。
- 发布能力可执行并在发布记录中查询到结果。
- 构建通过，菜单路由可达。
