# 注册记录与自动终端身份补齐（实施规划与实现结果）

## 1. 问题
1. 用户提交注册申请后，退出注册页面再进入“审核进度”无法看到上次申请记录。
2. 登录页暴露“终端编码”输入框，容易让用户误以为可手工指定终端身份，也存在填入其他设备终端编码的风险。

## 2. 实施规划
1. 注册记录改为本机留存优先  
   - 注册成功后将申请摘要写入本机 DataStore。
   - “审核进度/注册记录”默认展示本机提交过的记录。
   - 仅使用本机留存过的用户名刷新审核状态，不再通过登录页用户名直接查询远端注册记录，避免查看其他设备/其他用户申请。

2. 终端身份改为自动生成  
   - 客户端基于 Android ID、品牌、型号等生成稳定终端编号。
   - 登录页移除“终端编码”输入框。
   - 所有登录方式统一提交自动终端编号与设备指纹。

3. 后端增加终端复用校验  
   - 同一终端编号再次登录时，如后端已有设备指纹且与本次不一致，拒绝复用。

## 3. 实现结果
### 3.1 客户端
- 本机注册记录存储：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/core/storage/datastore/AppPreferenceStore.kt`
  - 新增 `LocalRegistrationRecord` 与本机记录列表。
- 注册成功后自动写入本机记录：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/domain/RegistrationRepository.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/ui/RegistrationViewModel.kt`
- 注册记录页默认展示本机记录：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/ui/RecordsScreen.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/ui/RegistrationScreen.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginScreen.kt`
- 自动终端身份：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/terminal/domain/TerminalIdentityProvider.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginViewModel.kt`
  - 登录页已移除终端编码手填输入。

### 3.2 后端
- 终端复用校验：
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/device/service/TerminalInfoService.java`
  - 已存在终端编号若绑定过设备指纹，本次设备指纹不一致则拒绝。

## 4. 验证结果
- 后端编译通过：`mvn -DskipTests package`
- 安卓编译通过：`./gradlew :app:compileDebugKotlin`
