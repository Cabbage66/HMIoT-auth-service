# 阶段8：信任评估结果接入与风险阻断联动（实施计划与实现结果）

## 阶段目标

完成信任评估结果接入、风险阻断状态持久化、访问链路阻断联动与解除闭环。

## 实施计划（详细）

1. 信任评估结果接入
- 调用 `POST /api/v1/trust-assessments/check` 获取 trusted/failReason 等结果。

2. 风险阻断状态模型
- 本地持久化阻断状态：`blocked`、`reason`、`updatedAt`。

3. 访问链路联动
- 访问前优先检查阻断状态。
- 若阻断中，直接拒绝并输出二次认证/解除提示。

4. 信任中心页面
- 手动触发信任评估。
- 展示阻断状态与原因。
- 支持手动解除阻断。

5. 自动联动
- 在终端采集 Worker 中同步触发信任评估并更新阻断状态。

## 实现结果

### 一、阻断状态持久化

- `HMIoTApp/app/src/main/java/com/hmiot/app/core/storage/datastore/AppPreferenceStore.kt`
  - 新增 `TrustGuardState`。
  - 新增 `trustGuardState` Flow 与 `updateTrustGuardState`。

### 二、信任阻断仓储

- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/trust/domain/TrustGuardRepository.kt`
  - `evaluateAndUpdate()`：调用信任检查并更新阻断状态。
  - `clearBlock()`：手动解除阻断。
  - `currentState()`：供访问链路快速读取。

### 三、访问链路阻断联动

- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/access/domain/AccessRepository.kt`
  - 访问前先读取阻断状态。
  - 阻断中直接返回拒绝决策并提示原因。

### 四、信任中心 UI

- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/trust/ui/TrustCenterViewModel.kt`
- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/trust/ui/TrustCenterScreen.kt`
  - 支持执行信任评估、查看状态、手动解除阻断。

### 五、自动任务联动

- `HMIoTApp/app/src/main/java/com/hmiot/app/core/work/TerminalCollectWorker.kt`
  - 在采集上报周期中增加信任评估更新动作。

### 六、容器与导航接入

- `HMIoTApp/app/src/main/java/com/hmiot/app/core/AppContainer.kt`
  - 注入 `TrustGuardRepository` 并传入访问仓储。
- `HMIoTApp/app/src/main/java/com/hmiot/app/MainActivity.kt`
  - 新增 `trust-center` 路由。
- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/home/ui/HomeScreen.kt`
  - 首页新增“信任中心”入口。
