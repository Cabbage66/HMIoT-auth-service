# 阶段4：生物特征采集与生命周期管理（实施计划与实现结果）

## 阶段目标

实现生物特征生命周期闭环：采集、上传/注册、重采、模板查询、认证记录查询。

## 实施计划（详细）

1. 声纹采集能力
- 使用麦克风采集 3 秒音频。
- 生成 16kHz mono PCM16 WAV，Base64 编码作为接口入参。

2. 声纹模板生命周期
- 接入声纹模板注册接口（`/voiceprints/enroll`）。
- 接入声纹重采接口（`/voiceprints/recollect`）。
- 接入我的模板查询接口（`/voiceprints/me`）。

3. 认证记录生命周期
- 接入我的声纹认证记录查询（`/voiceprints/auth-records/me`）。
- 接入我的动态生物认证记录查询（`/dynamic-biometrics/auth-records/me`）。
- 页面展示记录结果、分值、失败原因。

4. 生物中心整合
- 在生物中心页整合指纹入口、声纹采集与生命周期操作、动态生物记录查询。

5. 工程质量
- 分层实现（data/domain/ui）。
- 单测与打包通过。

## 实现结果

- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/domain/VoiceSampleCollector.kt`
