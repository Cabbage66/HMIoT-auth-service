# 阶段3：证书登录与生物认证入口（实施计划与实现结果）

## 阶段目标

完成证书登录辅助能力与生物认证入口能力，为后续生物特征采集与认证链路（阶段4+）提供可复用基础。

## 实施计划摘要

- 证书资料本地管理：新增证书信息保存/清理能力与页面入口。
- 本地生物认证入口：接入 `BiometricPrompt` 指纹认证。
- 服务端生物认证入口：接入声纹与动态生物健康检查、认证调用。
- 导航整合：登录页、首页新增对应入口，形成可演示路径。

## 实现结果

### 1) 证书登录辅助能力

已实现：
- 本地证书资料模型与持久化（序列号、指纹、PEM）：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/core/storage/datastore/AppPreferenceStore.kt`
- 证书资料仓储：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/certificate/domain/CertificateProfileRepository.kt`
- 证书资料管理页面与状态管理：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/certificate/ui/CertificateViewModel.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/certificate/ui/CertificateScreen.kt`
- 登录页入口：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginScreen.kt`

### 2) 本地生物认证入口（指纹）

已实现：
- 本地 `BiometricPrompt` 指纹认证触发、成功/失败/错误反馈：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/ui/BiometricScreen.kt`
- 生物认证状态管理：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/ui/BiometricViewModel.kt`

### 3) 服务端生物认证入口（声纹/动态生物）

已实现：
- 声纹健康检查 + 声纹认证调用：
  - `GET /api/v1/voiceprints/health`
  - `POST /api/v1/voiceprints/verify`
- 动态生物健康检查 + 动态生物认证调用：
  - `GET /api/v1/dynamic-biometrics/health`
  - `POST /api/v1/dynamic-biometrics/query`
- 客户端实现文件：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/data/BiometricApi.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/domain/BiometricRepository.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/ui/BiometricViewModel.kt`

### 4) 导航与依赖注入整合

已实现：
- 统一容器新增证书仓储与生物仓储：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/core/AppContainer.kt`
- 导航新增 `certificate`、`biometric` 路由，首页新增生物认证中心入口：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/MainActivity.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/home/ui/HomeScreen.kt`
