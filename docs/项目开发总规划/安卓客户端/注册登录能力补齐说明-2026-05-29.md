# 注册登录能力补齐说明（2026-05-29）

## 背景

根据安卓端验收反馈，原实现缺少“账号密码直接登录”主链路，且登录页未体现“直登+辅助登录”。

## 本次补齐内容

1. 后端新增用户账号密码登录接口
- `POST /api/v1/auth/password/login`
- 文件：
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/auth/dto/PasswordLoginRequest.java`
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/auth/service/PasswordLoginService.java`
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/auth/controller/AuthController.java`

2. 策略执行兼容账号密码认证
- 新增认证方式：`PASSWORD` / `PASSWORD_LOGIN`
- 默认登录/访问策略默认链路改为 `PASSWORD`
- 文件：
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/policy/service/PolicyExecutionService.java`

3. 安卓登录页改为双模式
- 支持“账号密码直登”与“证书登录（challenge/verify）”
- 密码模式下直接调用登录接口，不再走 challenge
- 文件：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/data/AuthApi.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/domain/AuthRepository.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginViewModel.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginScreen.kt`

4. 注册页完善
- 密码输入改为密文显示
- 文件：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/ui/RegistrationScreen.kt`

## 验证

- 后端：`mvn -q -DskipTests compile` 通过
- 安卓：`./gradlew :app:assembleDebug` 通过

## 说明

- 注册功能此前已存在（提交注册 + 审核进度查询）；当前系统流程是“注册后待审核（PENDING）”，审核通过后用户状态变为 `ENABLED` 才可登录。
