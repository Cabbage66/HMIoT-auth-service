# 阶段5：终端状态采集上报与本地清洗（实施计划与实现结果）

## 阶段目标

实现终端状态采集、数据清洗标准化、本地离线队列、服务端上报与重试、最近上报查询和信任检查。

## 实施计划（详细）

1. 终端采集器
- 采集设备、系统、内存、存储、电量、网络等状态。
- 生成结构化终端事件。

2. 本地清洗标准化
- 统一事件类型与等级。
- 剔除敏感键并限制 payload 规模。

3. 本地队列与重试
- 事件先入本地队列。
- 上报成功出队、失败留队。
- 队列上限保护（保留最近200条）。

4. 服务端联动
- 上报：`POST /api/v1/terminal-events/reports`
- 最近事件查询：`GET /api/v1/terminal-events/my/recent`
- 信任检查：`POST /api/v1/trust-assessments/check`

5. 自动与手动双通道
- Worker 周期任务：自动采集并尝试上报。
- 终端监控中心页面：手动采集、上报、回读、信任检查。

- 本地队列持久化（DataStore）：
