# 人脸全生命周期补齐（实施规划与实现结果）

## 1. 实施规划
1. 人脸能力从“本地模拟”切换为“真实模型服务”  
   - 后端新增人脸模型集成客户端，接入健康检查、模板注册、模板比对。  
   - 禁止 mock 协议，要求 HTTP(S) 模型地址（`FACE_SERVICE_URL`）。

2. 打通人脸模板生命周期与审批流程  
   - 新增 `faces` 用户侧接口：采集提交、注册绑定、补采替换、验证、模板查询、认证流水查询。  
   - 模板落库状态为 `PENDING`，复用管理端生物模板审核/撤销流程。  
   - 审核通过后自动替换旧激活模板，保留版本与留痕。

3. 打通人脸登录链路  
   - 新增 `auth/face/login` 的真实模型比对登录。  
   - 登录前执行终端绑定校验、策略链校验（动态生物/IoT），并写入真实认证流水。

4. 安卓端接入真实采集与调用  
   - 登录页人脸按钮改为采集图像后调用后端模型比对登录。  
   - 系统内“人脸信息”入口接入注册绑定/补采替换。  
   - 注册页采集的人脸样本随注册申请提交，后端预建待审核人脸模板。

## 2. 实现结果
### 2.1 后端
- 新增人脸模型集成：
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/integration/service/FaceIntegrationClient.java`
  - 配置项：`hmiot.integrations.face-service-url`（默认 `http://localhost:5005`）
- 新增人脸生命周期服务与接口：
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/biometric/service/FaceAuthService.java`
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/biometric/controller/FaceController.java`
  - 路由：`/api/v1/faces/health|enroll|recollect|verify|me|auth-records/me`
- 新增人脸登录服务：
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/auth/service/FaceLoginService.java`
  - `backend/src/main/java/com/hmiot/hmiot_backend/module/auth/dto/FaceLoginRequest.java`
  - `AuthController` 的 `/auth/face/login` 已切换到真实人脸登录服务
- 模板与审批能力补齐：
  - `BiometricTemplateService` 新增 `FACE` 类型生命周期方法（版本、查询、替换）
  - 审批通过会替换其他激活人脸模板，保持单主模板生效
- 注册流程补齐人脸提交：
  - `RegistrationSubmitRequest` 增加 `faceImageBase64/faceImageFormat`
  - `RegistrationService` 支持注册阶段创建待审核人脸模板

### 2.2 安卓端
- 登录接入真实人脸：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/data/AuthApi.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/domain/AuthRepository.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginViewModel.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginScreen.kt`
- 系统页面人脸管理接入：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/MainActivity.kt`
  - 点击“人脸信息”后执行相机采集并自动走注册绑定/补采替换
- 生物模块新增人脸API：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/data/BiometricApi.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/domain/BiometricRepository.kt`
- 注册页接入人脸样本提交：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/data/RegistrationApi.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/ui/RegistrationViewModel.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/registration/ui/RegistrationScreen.kt`

## 3. 验证结果
- 后端编译通过：`mvn -DskipTests package`
- 安卓编译通过：`./gradlew :app:compileDebugKotlin`

## 4. 管理端审批预留说明
- 人脸模板统一落库到 `biometric_template`，`biometricType=FACE`，`auditStatus=PENDING`。  
- 管理端继续使用现有生物模板审核接口（`/api/v1/biometric-templates/**`）即可完成人脸审批、驳回、撤销与审计留痕。
