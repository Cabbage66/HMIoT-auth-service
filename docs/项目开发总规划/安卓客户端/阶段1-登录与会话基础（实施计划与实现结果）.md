# 阶段1：登录与会话基础（实施计划与实现结果）

## 阶段目标

实现安卓客户端登录主链路与会话基础能力，达到后续注册、生物认证、策略执行阶段可直接扩展的工程基线。

## 实施计划（详细）

1. 网络与协议层
- 统一 `ApiResponse` 协议解析。
- 接入认证接口：`/api/v1/auth/certificate/challenge`、`/api/v1/auth/certificate/verify`。
- 增加鉴权拦截器：自动注入 `Authorization` 与 `X-Trace-Id`。

2. 会话与本地存储
- 持久化字段：token、tokenType、userId、username、realName、authMethod、terminalId、terminalCode、clientType。
- 提供登录态恢复与退出清理。

3. 业务分层
- `feature/auth/data`: API 与请求响应模型。
- `feature/auth/domain`: `AuthRepository`（challenge、verify、受保护接口探测、logout）。
- `feature/auth/ui`: `LoginViewModel` + 状态机界面。

4. UI流程
- 证书认证流程（challenge/verify）。
- challenge 获取、签名输入、verify 提交。
- 展示 `sessionId/challengeId/expiresAt`、错误与 `traceId`。
- 登录成功后进入首页，可执行退出登录。

5. 工程质量
- 增加错误映射组件 `NetworkErrorMapper`。
- 增加 JVM 单测覆盖错误映射。
