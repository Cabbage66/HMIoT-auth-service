# 阶段7：应用资源访问、认证协议引导与二次认证（实施计划与实现结果）

## 阶段目标

完成应用资源访问与认证协议引导闭环，实现访问前策略判断、信任检查与二次认证提示能力。

## 实施计划（详细）

1. 接口接入
- 应用资源列表：`GET /api/v1/apps`
- 信任检查：`POST /api/v1/trust-assessments/check`
- 票据签发：`POST /api/v1/tickets/issue`
- SSO访问：`POST /api/v1/sso/access`

2. 访问编排逻辑
- 加载资源后，先执行信任检查。
- 使用本地策略引擎评估是否允许访问。
- 不满足策略时触发二次认证提示。
- 满足时调用 SSO 访问完成应用访问链路。

3. 页面整合
- 新增访问中心页面，支持“加载资源 + 访问应用（策略引导）”。
- 首页新增“应用访问中心”入口。
