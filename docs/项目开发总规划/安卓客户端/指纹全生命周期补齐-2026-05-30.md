# 指纹全生命周期补齐（实施规划与实现结果）

## 1. 实施规划
1. 登录链路改造为真实指纹签名登录  
   - 安卓端改为 `challenge -> BiometricPrompt(CryptoObject)签名 -> login`。  
   - 后端校验签名、公钥模板、终端绑定与策略链，写入真实认证流水并签发 JWT。

2. 指纹模板生命周期打通  
   - 安卓端接入指纹模板 `challenge/enroll/recollect/me/auth-records`。  
   - 使用 Android Keystore 生成密钥对并绑定生物认证，提交公钥与签名到后端。  
   - 支持“首次注册绑定”和“已存在模板时补采替换”。

3. 管理端审批流程预留/对齐  
   - 指纹模板落库状态为 `PENDING`，复用管理端生物模板审核接口。  
   - 审核通过后替换旧模板生效，审核失败保留原因留痕。

## 2. 实现结果
### 2.1 安卓端
- 新增指纹密钥与签名能力：
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/domain/FingerprintKeyId.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/domain/FingerprintCryptoManager.kt`
- 登录页指纹按钮改为真实流程：  
  `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginScreen.kt`
  - 先请求 `/auth/fingerprint/challenge`
  - 调起系统指纹并对 challenge 做私钥签名
  - 提交 `/auth/fingerprint/login`
- 登录数据层改造：  
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/data/AuthApi.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/domain/AuthRepository.kt`
  - `HMIoTApp/app/src/main/java/com/hmiot/app/feature/auth/ui/LoginViewModel.kt`
- 首页/我的“指纹信息”入口接入真实注册/补采：  
  `HMIoTApp/app/src/main/java/com/hmiot/app/MainActivity.kt`
  - 自动判断已有模板：无模板走注册，有模板走补采
  - 提交后显示模板ID、审核状态、模型版本
- 生物仓库新增指纹接口封装：  
  `HMIoTApp/app/src/main/java/com/hmiot/app/feature/biometric/domain/BiometricRepository.kt`

### 2.2 后端
- 新增指纹自服务接口（采集挑战、注册、补采、验证、模板查询、认证记录查询）：  
  `backend/src/main/java/com/hmiot/hmiot_backend/module/biometric/controller/FingerprintController.java`
- 新增指纹登录 challenge/login 真实签名校验服务：  
  `backend/src/main/java/com/hmiot/hmiot_backend/module/auth/service/FingerprintLoginService.java`
- 指纹模板生命周期服务补齐（版本、查询、替换逻辑）：  
  `backend/src/main/java/com/hmiot/hmiot_backend/module/biometric/service/BiometricTemplateService.java`
- 审批流程预留：指纹模板进入 `PENDING`，可通过既有管理端模板审核接口审批。
