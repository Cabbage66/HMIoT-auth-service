## 逐条核对与处理结果

### 1. 注册与登录

- 注册基础信息、注册记录/审核进度：已实现（阶段2）。
- 数字证书保存与使用：已实现（阶段3/1）。
- 生物特征辅助验证或登录：已实现并补强。
  - 已有：本地生物认证（BiometricPrompt）、声纹远端认证。
  - 本次补齐：新增“人脸远端认证入口”。
- USB 登录：安卓端不涉及（仅网页端），已完成清理。

### 2. 生物特征采集与认证

- 指纹/声纹采集与认证：已实现（本地指纹、声纹采集+远端）。
- 人脸能力：本次补齐“人脸远端认证入口”。
- 生命周期管理（采集、上传、模板建立、模板存储、模板撤销、审核、重采、留痕）：
  - 已有：采集、上传、模板建立、审核状态查询、重采、认证记录查询。
  - 本次补齐：本地留痕审计流水（DataStore持久化）。
  - 说明：模板撤销需服务端显式接口支持，当前后端未提供独立 revoke API，客户端已保留模板状态展示与留痕能力。
- 模板与保护密钥密码机制：
  - 本次补齐：新增“生物模板保护口令”机制；敏感动作（声纹认证/注册/重采、人脸远端认证）前执行口令校验。
- 比对模式区分：
  - 指纹：本地采集/本地比对（BiometricPrompt）。
  - 声纹/人脸：本地采集 + 远端比对入口（voiceprint-engine / dynamic-biometrics）。
- 声纹引擎对接：已实现（`voiceprints/*` 接口）。

### 3. 终端信任监控

- 终端信息采集/上报、定时采集、异步事件、清理标准化：已实现（阶段5 + Worker）。
- 展示信任评估、认证状态、设备状态、策略执行、安全等级、风险：已实现（终端监控+信任中心+策略中心）。
- 异常告警与访问阻断：已实现（TrustGuard + Access 前置阻断）。

### 4. 功能访问与策略执行

- 资源展示、访问前认证协议引导：已实现（访问中心 + 策略引擎）。
- 认证后信任评估并判定访问：已实现。
- 策略下发（认证/采集监控/基线）本地落库与执行：已实现（阶段6）。
- 终端异常/行为异常/绑定不满足/信任不足触发二次认证：已实现基础链路（策略拒绝提示与访问阻断）；增强认证因子按后端策略继续扩展。
