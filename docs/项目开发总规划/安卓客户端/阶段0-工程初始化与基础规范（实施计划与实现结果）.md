# 阶段0：工程初始化与基础规范（实施计划与实现结果）

## 阶段目标

将空安卓工程升级为可持续迭代的业务基线工程，为阶段1-9提供统一架构、依赖与目录规范。

## 实施计划

- 统一应用标识与工程配置：包名、SDK、构建配置。
- 落地客户端基础依赖：Compose、Navigation、Retrofit/OkHttp、DataStore、WorkManager、Biometric、CameraX。
- 建立目录骨架：`core`、`feature`、`ui/theme`。
- 建立入口流程骨架：`splash -> login -> home`。
- 建立后台任务骨架：策略同步、终端采集两个周期任务。
- 建立网络与本地存储最小能力：健康检查 API、会话 token DataStore。
- 文档化阶段成果与后续边界。

## 实现结果

已完成：

- `HMIoTApp/app/build.gradle.kts`：补齐阶段0依赖与 Java 17 编译配置。
- `HMIoTApp/app/src/main/AndroidManifest.xml`：补齐网络、生物、音视频采集相关权限，配置 `HmiotApplication` 与网络安全配置。
- `HMIoTApp/app/src/main/java/com/hmiot/app/HmiotApplication.kt`：启动时注册 `policy-sync` 与 `terminal-collect` 周期任务。
- `HMIoTApp/app/src/main/java/com/hmiot/app/MainActivity.kt`：建立三段式导航骨架。
- `HMIoTApp/app/src/main/java/com/hmiot/app/core/network/*`：提供统一 `Retrofit` 客户端与 `health` 基础接口。
- `HMIoTApp/app/src/main/java/com/hmiot/app/core/storage/datastore/AppPreferenceStore.kt`：提供会话 token 存取。
- `HMIoTApp/app/src/main/java/com/hmiot/app/core/work/*`：提供策略同步、终端采集 Worker 占位实现。
- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/**`：提供 `splash/login/home` 页面占位实现。

阶段0取舍：

- Room 持久化已在规划内，但因当前 AGP9 + 内置 Kotlin 与 KSP 组合存在兼容约束，阶段0先采用 DataStore 保证可推进，Room 在阶段1采用稳定方案接入（`kapt` 或兼容 KSP 版本）并补迁移脚本。

## 验收结论

- 代码骨架层面：通过，已具备阶段1开发条件。
- 构建验收：本地执行 `:app:assembleDebug` 过程中，受环境 TLS 握手失败影响，未完成远程依赖拉取后的最终打包；错误为外部仓库连接问题，不是业务代码编译错误。

## 阶段1入口条件检查

- 工程结构已可承载登录/注册/会话功能开发。
- 网络、任务调度、基础存储能力已就绪。
- 可进入阶段1：登录、会话与后端认证接口联调。
