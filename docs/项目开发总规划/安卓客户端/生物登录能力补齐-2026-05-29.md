# 生物登录能力补齐（2026-05-29）

## 目标
实现用户通过指纹、人脸、声纹直接登录系统；当原后端逻辑不足时补齐后端登录签发能力。

## 本次补齐内容

### 1. 后端新增三类登录接口（签发真实登录令牌）
- `POST /api/v1/auth/fingerprint/login`
- `POST /api/v1/auth/face/login`
- `POST /api/v1/auth/voiceprint/login`

以上接口均完成：
- 用户状态校验（仅 `ENABLED` 可登录）
- 终端解析/注册
- 用户-终端绑定校验
- 策略校验（登录策略）
- 物联网设备约束校验（按策略）
- 登录审计记录
- 成功后签发 JWT 并返回登录会话信息

其中声纹登录额外完成：
- 使用用户已审核通过声纹模板做远端比对（`voiceprint-engine`）
- 写入声纹认证流水（成功/失败）
- 写入外部集成调用记录

### 2. 策略引擎兼容补齐
- 扩展已实现认证方式集合，支持：
  - `FINGERPRINT/FINGERPRINT_LOGIN`
  - `FACE/FACE_LOGIN`
  - `VOICEPRINT/VOICEPRINT_LOGIN`
- 补齐策略方法匹配映射，避免生物登录被策略层误拒绝。
- 补齐生物登录信任等级映射（用于后续票据/访问链路）。

### 3. 安卓端登录链路接入
- 登录页“指纹/人脸/声纹”按钮全部接入真实后端登录：
  - 指纹：系统 `BiometricPrompt` 成功后调用 `fingerprint/login`
  - 人脸：摄像头采集检测成功后调用 `face/login`
  - 声纹：麦克风采样后调用 `voiceprint/login`
- 保留账号密码与证书登录主链路不受影响。
