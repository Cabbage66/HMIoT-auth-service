# 阶段2：注册与审核进度查询（实施计划与实现结果）

## 阶段目标

实现安卓客户端用户注册提交与审核进度查询完整链路，满足需求中“注册与登录”子项里对注册记录、审核进度、审核结果查询的要求。

## 实施计划（详细）

1. 后端能力补齐
- 新增公开注册接口：
  - `POST /api/v1/registrations`：提交注册申请。
  - `GET /api/v1/registrations/progress`：按用户名查询审核进度。
- 落库逻辑：
  - `user_account` 新增用户（`PENDING`、`ONLINE`）。
  - `registration_request` 新增申请记录与原始请求摘要。
- 审计：
  - 记录注册提交与进度查询系统审计日志。
- 安全策略：
  - 放行 `/api/v1/registrations/**`，用于未登录用户注册。

2. 安卓端实现
- 新增注册模块：
  - 数据层 `RegistrationApi`。
  - 领域层 `RegistrationRepository`。
  - 表现层 `RegistrationViewModel` + `RegistrationScreen`。
- 功能流程：
  - 填写注册信息并提交。
  - 按用户名查询审核进度。
  - 展示申请记录、审核状态、驳回原因。
- 导航集成：
  - 登录页新增“去注册/查审核进度”入口。
  - 注册页可返回登录页。

3. 工程质量与验证
- 后端编译校验。
- 安卓单测与打包校验。
