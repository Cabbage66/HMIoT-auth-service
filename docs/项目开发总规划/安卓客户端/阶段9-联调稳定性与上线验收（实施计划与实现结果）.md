# 阶段9：联调稳定性与上线验收（实施计划与实现结果）

## 阶段目标

完成客户端关键链路联调验收能力建设，提供可重复执行的一键验收机制，作为上线前稳定性检查基础。

## 实施计划（详细）

1. 一键验收能力
- 增加“上线验收中心”。
- 一次执行关键链路检查并汇总通过率。

2. 核心验收链路
- 策略同步检查。
- 应用资源加载检查。
- 信任评估检查。
- 终端事件上报检查。
- SSO访问演练检查。

3. 结果可视化
- 展示每项检查的 PASS/FAIL 与明细。
- 输出总体通过统计，便于回归对比。

4. 与现有模块联动
- 复用阶段5~8的仓储能力，避免重复逻辑。

## 实现结果

### 一、上线验收仓储

- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/release/domain/ReleaseValidationRepository.kt`
  - 实现 `runAllChecks()`。
  - 验收项包括：策略同步、应用资源加载、信任评估、终端事件上报、SSO访问演练。

### 二、上线验收 UI

- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/release/ui/ReleaseCenterViewModel.kt`
- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/release/ui/ReleaseCenterScreen.kt`
  - 提供“执行一键验收”按钮。
  - 展示总通过数与每项检查结果。

### 三、导航与容器接入

- `HMIoTApp/app/src/main/java/com/hmiot/app/core/AppContainer.kt`
  - 注入 `ReleaseValidationRepository`。
- `HMIoTApp/app/src/main/java/com/hmiot/app/MainActivity.kt`
  - 新增 `release-center` 路由。
- `HMIoTApp/app/src/main/java/com/hmiot/app/feature/home/ui/HomeScreen.kt`
  - 首页新增“上线验收中心”入口。

## 阶段结论

阶段9已按完整功能完成，客户端具备上线前联调与稳定性一键验收能力。
