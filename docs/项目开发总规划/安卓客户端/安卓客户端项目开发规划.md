# 安卓客户端项目开发规划

## 目标

在 `HMIoTApp` 实现可上线安卓客户端，覆盖注册登录、生物特征采集、终端信任采集、策略执行、应用访问，并与 `backend` 阶段0-10完成联调，满足《项目需求-整理版》《测试方案_回忆版》要求。

## 分阶段安排

- 阶段0：工程初始化与基础规范
- 阶段1：登录、会话与基础接口联调
- 阶段2：注册与审核进度查询
- 阶段3：证书登录与生物认证入口
- 阶段4：生物特征采集与生命周期管理
- 阶段5：终端状态采集、上报与本地清洗
- 阶段6：策略同步、本地策略库与执行引擎
- 阶段7：应用资源访问、认证协议引导与二次认证
- 阶段8：信任评估结果接入与风险阻断联动
- 阶段9：全链路联调、稳定性与上线验收

## 阶段出口标准（统一）

- 每阶段均可编译、可安装、可演示。
- 关键流程具备最小自动化测试或可复现手工测试步骤。
- 与后端接口字段、错误码、鉴权机制保持一致。
- 审计留痕字段在客户端请求上下文中完整传递（traceId、terminalId、policyVersion 等）。
