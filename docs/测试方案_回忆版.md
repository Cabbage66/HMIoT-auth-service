# 测试方案

## 用户管理

* 步骤：前置条件，后量子密码服务系统（其他系统）已经具备用户A的用户属性信息，且与本系统连接成功。
  1. 使用用户管理功能，能够查看用户的信息，信息能够正常显示
  2. 使用用户身份属性信息获取，调用后量子（任务2的其他系统）部分的身份属性部分
  3. 再次查看用户信息，相关信息已经发生改变



## 公用密码身份认证与终端绑定

* 步骤：
  1. 用户A在终端1上插入USB认证密码模块，输入对应pin，可以正常登录系统。
  2. 用户A访问某应用，成功
  3. 用户A在终端2上插入USB认证密码模块，输入对应pin，可以正常登录。
  4. 用户A访问某应用，成功
  5. 本系统（人机物系统）管理员操作，绑定用户A与终端1
  6. 用户A在终端1上再次认证，可正常登录并成功访问应用
  7. 用户A在终端2上插入USB认证密码模块，输入对应pin，无法登录



## 动态生物特征绑定

* 步骤：前置条件，动态生物特征服务系统（其他系统）已经采集用户A的特征，且与本系统连接成功。
  1. 人机物系统（本系统）管理员操作，将用户A与其步态等动态生物特征绑定
  2. 用户A进行步态识别后成功后，用户A在终端1上插入USB认证密码模块，输入对应pin，可以正常登录系统。
  3. 用户A访问某应用，成功
  4. 用户B在终端1使用用户A的USB认证密码模块，输入pin，无法登录（即验证用户B步态不符）



## 广域低功耗系统绑定（物联网设备）

* 步骤：前置条件，广域低功耗服务系统接入正常
  1. 人机物系统（本系统）管理员操作，将用户A与其广域低功耗设备绑定
  2. 终端1模拟物联网设备接入，
  3. 用户A在终端1上插入USB认证密码模块，输入对应pin，可以正常登录系统。
  4. 用户A访问某应用，成功
  5. 终端1模拟物联网设备接入后，用户B在终端1使用用户B的USB认证密码模块，输入pin，无法登录



## 两个人机物系统之间

* 步骤：
  1. 用户A在人机物系统A登录正常
  2. 用户A访问人机物系统B的应用B
  3. 用户A无需在人机物系统B中再次登录即可成功访问B



## 跨域访问

* 步骤：前置条件，与异构跨域服务系统连接正常
  1. 用户A在人机物系统登录
  2. 用户A需要使用其他系统C中的应用C
  3. 使用异构跨域服务
  4. 用户A成功访问系统C中的应用C
