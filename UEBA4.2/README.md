# r4.2 數據集 UEBA 異常檢測系統

## 項目概述

本項目實現了針對 **r4.2 數據集**的**用戶和實體行為分析（UEBA）**異常檢測系統，採用基於 **Isolation Forest** 的無監督機器學習方法，對多維度用戶行為進行異常檢測和風險評估。

### 適配來源

本系統基於 **車網整理** 項目中的無監督檢測方法，將原本用於車聯網充電桩和用戶行為的檢測技術適配到企業內部威脅檢測場景。

## 檢測維度

### 1. 用戶登錄行為檢測 (logon.csv)

**數據源**: `r4.2/logon.csv`  
**算法**: Isolation Forest  
**特徵數**: ~40 個

**主要特徵**:
- **基礎統計**: 登錄總數、活躍天數、使用PC數量
- **時間模式**: 深夜登錄比例、工作時段比例、周末登錄比例、時間熵
- **時間間隔**: 平均登錄間隔、短間隔比例、長間隔比例
- **PC使用**: 主要PC使用比例、PC多樣性
- **近期活躍度**: 1/3/7/14/30天活躍度及變化趨勢

**異常指標**:
- 深夜頻繁登錄
- 異常登錄間隔模式
- 跨多台PC登錄
- 活躍度突增

## 技術方案

### 核心算法：Isolation Forest

**選擇理由**:
1. **專為異常檢測設計**: 直接針對異常樣本，無需正常樣本標註
2. **高維數據性能優異**: 適合處理40-60維的行為特徵
3. **訓練速度快**: 適合大規模數據集
4. **魯棒性強**: 對異常值本身不敏感

**工作原理**:
- 通過隨機森林構建多棵孤立樹
- 異常樣本更容易被孤立（路徑更短）
- 根據平均路徑長度計算異常分數

---

### 特徵工程策略

#### 1. 頻率特徵
- 總活動次數、每日平均次數、活躍天數

#### 2. 時間模式特徵
- 深夜/工作時段/周末活動比例
- 時間分布熵（衡量行為規律性）

#### 3. 時間間隔特徵
- 平均間隔、標準差、最大/最小間隔
- 短間隔/長間隔比例

#### 4. 近期活躍度特徵
- 1/3/7/14/30天的活動統計
- 近期與歷史對比比率

#### 5. 多樣性特徵
- PC/域名/收件人/文件類型多樣性
- 集中度指標

---

### 風險等級劃分

| 風險等級 | 異常分數範圍 | 說明 |
|---------|-------------|------|
| **正常 (0)** | score > 第25百分位 | 用戶行為正常 |
| **低風險 (1)** | 第10-25百分位 | 輕微異常，需關注 |
| **中風險 (2)** | 第5-10百分位 | 明顯異常，需警惕 |
| **高風險 (3)** | score < 第5百分位 | 嚴重異常，需立即處理 |

**註**: Isolation Forest的異常分數越低表示越異常

## 綜合風險評估

### 評分方法

**加權綜合分數計算**:
```
weighted_risk_score = 
    0.25 × logon_risk + 
    0.20 × device_risk + 
    0.25 × file_risk + 
    0.15 × http_risk + 
    0.15 × email_risk
```

**綜合風險等級**:
- **正常**: weighted_risk_score < 0.5
- **低風險**: 0.5 ≤ weighted_risk_score < 1.0
- **中風險**: 1.0 ≤ weighted_risk_score < 2.0
- **高風險**: weighted_risk_score ≥ 2.0

### 可視化報告包含

1. **綜合風險等級分布** (餅圖)
2. **各維度風險分布** (堆疊柱狀圖)
3. **異常維度數量分布** (柱狀圖)
4. **加權風險分數分布** (直方圖)
5. **高風險用戶熱力圖** (TOP 50)
6. **各維度異常分數箱線圖**
7. **統計摘要表格**

## 常見問題

### Q1: 為什麼選擇 Isolation Forest？

A: Isolation Forest 是專門為異常檢測設計的算法，優勢包括：
- 無需標註數據
- 高維數據性能好
- 訓練速度快
- 對異常值魯棒

### Q2: 如何處理大文件（http.csv, email.csv）？

A: 系統支持採樣模式：
```python
detector.load_data(file_path, sample_size=500000)
```

### Q3: 如何調整風險閾值？

A: 修改各檢測器中的 `percentiles` 參數：
```python
detector.train(features_df, contamination=0.1)  # 調整異常比例
detector.set_thresholds(scores, percentiles=[25, 10, 5])  # 調整閾值百分位
```

### Q4: 如何解釋異常用戶的具體原因？

A: 查看用戶在各維度的風險等級和原始特徵值，重點關注：
- 異常維度數量
- 各維度風險等級
- 近期活躍度變化趨勢
