系统前端风格文档集

用于评审和展示，不依赖登录，不连接后端。

总览 风格系统 登录页风格 管理员页风格 用户页风格

整理目标

基于现有 `trust/frontend` 的视觉实现，提炼统一的 UI 语言，并生成可直接查看的页面文档。文档聚焦「风格、布局、组件语义」，不包含业务接口与后端逻辑。

视觉基调

  • 后台工作台风格，强调稳定、清晰、可读性。
  • 头部采用渐变色带，内容区使用浅灰底 + 白卡片。
  • 图标与数据卡配合高饱和渐变做信息分层。

信息结构

  • 固定顶栏 + 左侧导航 + 面包屑 + 内容卡片。
  • 核心指标优先使用 4 宫格统计卡片展示。
  • 图表/活动/状态块采用并列布局组织二级信息。

组件特征

  • 圆角主导：按钮/输入/卡片统一 6-12px 圆角。
  • 悬浮阴影偏轻：强调层次但不过度立体。
  • 状态色继承 Element Plus 语义色体系。
