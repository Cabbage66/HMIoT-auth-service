页面风格要点

  • 头部用深色渐变，承载系统级品牌与角色信息。
  • 侧栏白底，激活态通过浅蓝底 + 蓝色边条强调定位。
  • 统计卡优先使用高彩渐变，强化“总览面板”的数据感。
  • 图表区与活动区采用白卡并列，形成主次信息双栏。

适用页面

  • 管理驾驶舱（Dashboard）
  • 策略配置中心
  • 用户/资源/设备管理页
  • 跨域访问与审计类页面
