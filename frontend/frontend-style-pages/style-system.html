布局规则

  • 页面容器优先使用 `el-container` 纵横组合。
  • 顶栏固定，内容区使用面包屑 + 卡片区块。
  • 大屏常见结构：`4列统计卡 + 2列内容区`。
  • 移动端在 768/960 断点下收敛为单列。

组件风格

  • 菜单激活：浅蓝底 + 蓝色文字 + 右侧高亮边。
  • 卡片 hover：位移或阴影轻微增强，避免强动画。
  • 状态通过 Tag/Progress/Alert 传达，颜色语义统一。
  • 图标与数字组合的「统计卡」是核心视觉单元。

微交互与可用性

  • 过渡时间以 0.2s~0.3s 为主，强调“快反馈”。
  • 滚动条自定义为浅灰系，保持中性低干扰。
  • 按钮、输入、列表项 hover 都有明确反馈状态。
  • 中文信息密度较高时优先保证对齐和留白节奏。
