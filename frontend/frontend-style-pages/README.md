# frontend-style-pages

本目录是系统前端风格文档集，全部为静态页面，不依赖登录和后端。

## 查看方式

1. 直接在文件管理器双击 `index.html` 打开。
2. 或在浏览器中打开 `docs/frontend-style-pages/index.html`。

## 页面说明

- `index.html`：文档导航与风格总览
- `style-system.html`：视觉规则与样式系统
- `page-login.html`：登录页风格示意
- `page-admin-dashboard.html`：管理员页面风格示意
- `page-user-overview.html`：用户页面风格示意
- `assets/base.css`：共享样式
